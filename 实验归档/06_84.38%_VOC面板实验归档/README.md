# BPD-MLP 264 VOC 面板实验（内部验证 Accuracy = 84.38%）

## 1. 实验目的

本实验基于 BPD VOC 数据，研究不同 VOC 特征选择频率阈值对 MLP 分类表现的影响，并对筛选出的稳定 VOC 进行统计差异分析和 PCA 可视化。

本归档以选择频率严格大于 60% 的 264 个 VOC 面板作为主要分析对象。

## 2. 数据基本信息

| 项目 | 数量 |
|---|---:|
| 原始样本 | 159 |
| 原始 VOC 特征 | 1692 |
| Class 1 | 53 |
| Class 2 | 53 |
| Class 3 | 53 |
| 二分类 Class 0（原始1+2） | 106 |
| 二分类 Class 1（原始3） | 53 |

原始 MAT 数据不公开，由数据提供方通过单独申请或授权方式提供。

数据文件预期名称：

`voc_dataset_table1_1+2_vs_3_bpd.mat`

数据应包含 X、y、原始类别和 VOC 特征名称及索引等字段。

## 3. VOC 选择频率筛选

根据10个冠军模型的特征选择频率进行筛选。

| 筛选条件 | VOC数量 |
|---|---:|
| >60% | 264 |
| >70% | 94 |
| >80% | 16 |
| >85% | 16 |
| >90% | 2 |
| =100% | 2 |

主要实验采用：

Selection Frequency > 0.60

最终得到264个稳定 VOC。

## 4. MLP 分类实验

主要实验使用264个稳定 VOC。

内部数据划分：

- 原始样本：159
- 开发集：127
- 独立测试集：32
- 内部训练集：95
- 内部验证集：32

模型训练参数：

- Epochs：30
- Random Seed：42
- Batch Size：16
- Learning Rate：0.0005
- Weight Decay：0.005
- Positive Class Weight：1.0
- Decision Threshold：0.5

注意：本目录中的84.38%为内部验证集结果，不是独立测试集结果。

## 5. 内部验证结果

| 指标 | 结果 |
|---|---:|
| VOC数量 | 264 |
| Accuracy | 84.375% |
| Sensitivity | 81.82% |
| Specificity | 85.71% |
| F1 | 78.26% |
| AUC（Softmax记录） | 0.837662 |

另行使用原始 Logit 差值计算 ROC，得到 AUC = 0.831169。两种评分产生的 AUC 不一致，正式论文报告前需要核实原始预测输出和数值饱和问题。

## 6. 统计分析

### 6.1 Mann–Whitney U 检验

对264个稳定 VOC 进行两组差异检验，并使用 Benjamini–Hochberg 方法进行 FDR 校正。

当前探索性分析结果：

- 原始 P < 0.05：30个
- FDR < 0.05：6个
- FDR < 0.01：4个

### 6.2 PCA 分析

使用264个稳定 VOC，对159个样本进行探索性 PCA 分析。

预处理：

1. log1p 转换
2. Z-score 标准化
3. PCA 降维

分别展示二分类和三分类样本得分分布。

### 6.3 ROC 分析

使用32个内部验证样本的预测评分绘制 ROC 曲线，并采用 Bootstrap 方法估计95%置信区间。

该结果属于内部验证分析。

## 10. 研究限制

1. 当前样本总量为159，样本规模较小。
2. 84.38%是内部验证结果，不代表独立测试集泛化性能。
3. U检验和 PCA 使用全部159个样本，属于探索性分析。
4. VOC 特征筛选与差异分析使用了同一批样本，显著性结果需要独立队列验证。
5. 100%选择频率不等同于已验证的临床生物标志物。
