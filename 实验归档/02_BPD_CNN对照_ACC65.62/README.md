# BPD-CNN 同数据对照实验

## 1. 实验目的

在原有 BPD 特征选择机制不变的基础上，将 MLP 分类器替换为 1D CNN，研究不同分类器对 VOC 二分类效果的影响。

## 2. 数据集

- 样本数：159
- 原始 VOC 特征数：1692
- 开发集 A：127
- 独立测试集 B：32
- 数据：原始表一数据
- 不进行 0.5 阈值置零处理

## 3. 实验参数

- K-means：3 类
- 随机种子：42
- 开发集随机划分：10 次
- 每次候选模型：10 个
- Epoch：30
- 稳定 VOC 筛选阈值：大于 60%
- 分类器：1D CNN

## 4. 独立测试集结果

- Accuracy：65.62%
- Sensitivity：0%
- Specificity：100%
- F1：0
- AUC：0.6190

## 5. 实验结论

在当前网络结构和数据条件下，CNN 的分类效果低于原始 MLP，尤其是正类识别能力不足。后续需要进一步研究卷积结构和 VOC 特征排列方式。

## 6. 主要文件

- modules_CNN.py：CNN 模型结构
- testing_CNN.ipynb：CNN 实验代码
- 结果：训练记录、模型权重、测试指标和 ROC 图

本实验使用独立测试集 B 进行最终评价。
