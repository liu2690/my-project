# 264 VOC 的 L2 正则化逻辑回归实验

## 1. 实验目的

使用 BPD 原实验筛选出的 264 个稳定 VOC，单独训练逻辑回归分类器，研究加入 L2 正则化后的分类效果，并与原 BPD 模型进行对照。

## 2. 数据集

- 总样本数：159
- 原始 VOC 特征数：1692
- 筛选后 VOC 数量：264
- 开发集 A：127
- 内部训练集：95
- 内部验证集：32

## 3. 实验方法

- 分类器：Logistic Regression
- 特征标准化：StandardScaler
- 正则化方式：L2
- 优化算法：liblinear
- 最大迭代次数：5000
- 分类阈值：0.5
- 正则化参数 C：0.001、0.01、0.1、1、10

其中 C 越小，正则化越强。

## 4. 内部验证结果

| C | Accuracy | F1 | AUC |
|---|---:|---:|---:|
| 0.001 | 53.13% | 0.5714 | 0.8182 |
| 0.01 | 71.88% | 0.6667 | 0.8658 |
| 0.1 | 78.13% | 0.7200 | 0.8701 |
| 1 | 75.00% | 0.6667 | 0.8831 |
| 10 | 78.13% | 0.6957 | 0.8918 |

最高 Accuracy 为 78.13%，C=0.1 和 C=10 时均达到该结果；最高 AUC 为 0.8918，对应 C=10。

## 5. 实验结论

不同 L2 正则化强度会影响逻辑回归的分类结果。C=0.1 时 F1 较高，C=10 时 AUC 最高。

本实验使用开发集内部验证，不作为独立测试集的最终泛化性能。

## 6. 主要文件

- run.py：可复现入口；从公开 CSV 重建 264 VOC mask 和固定数据划分
- 264VOC_L2正则化逻辑回归.py：实验代码
- logistic_regression_264.csv：不同 C 参数的实验结果

本实验用于与原 BPD 分类模型进行对照。

## 7. 复现

从仓库根目录运行：

```bash
python "实验归档/04_264VOC_L2逻辑回归_ACC78.13/run.py" --check
python "实验归档/04_264VOC_L2逻辑回归_ACC78.13/run.py"
```

`run.py` 从实验 01 的 `stable_features.csv` 读取 264 个 `VOC_Index`，并用种子 42/1042 重建外层和内部划分，不依赖未上传的 `.npy/.npz`。新结果写入 `result/reproduced/04_logistic_regression/`。
